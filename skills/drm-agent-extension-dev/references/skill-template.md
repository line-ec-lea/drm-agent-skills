## チェックリスト

- [ ] 実体が `.agents/skills/<name>/` にあり、`.claude/skills/<name>` がシンボリックリンクになっている（コピー禁止）
- [ ] frontmatter の name がフォルダ名と一致している（小文字・数字・ハイフンのみ）
- [ ] description に機能と発動キーワードの両方がある
- [ ] allowed-tools が実際に使うツールだけになっている
- [ ] 期間の定義が JST 基準で書かれている
- [ ] 判定基準がパターンとして明文化されている（「いい感じに」がない）
- [ ] ゼロ件時の挙動が定義されている
